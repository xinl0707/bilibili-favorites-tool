# 📺 B站收藏夹工具

一个基于 Python + Flask 的 B 站个人收藏夹爬取与可视化浏览工具。

> 一键爬取你在 B 站的所有收藏夹，自动下载视频封面和 UP 主头像，在网页端可视化浏览、搜索、排序、筛选，自动识别学习教程类视频，并支持导出 Excel。

## ✨ 功能特性

- 🕷️ **爬取收藏夹** — 从 B 站 API 爬取所有收藏夹的视频信息（标题、UP 主、播放量、收藏量、弹幕数、时长、上传/发布/收藏时间等）
- 🖼️ **自动下载图片** — 多线程下载视频封面和 UP 主头像，本地缓存浏览
- 📖 **可视化浏览** — 网页端浏览全部视频，支持搜索、按收藏量/播放量/弹幕数排序、按分类筛选
- 📚 **学习精选** — 自动识别并筛选出学习、知识、教程类视频，按子分类聚合展示
- 🏷️ **分类统计** — 按收藏夹名和标题关键词自动归类
- 📥 **Excel 导出** — 一键导出三种报表：收藏夹信息、学习教程精选、有价值视频推荐（Top100）
- 🗂️ **多快照管理** — 每次爬取生成独立快照，可随时切换、对比、删除历史数据
- 🧠 **智能错误诊断** — 内置错误知识库，对 Cookie 过期、风控、网络、存储等异常自动分类并给出解决方案

## 🚀 快速开始

### 环境要求

- Python 3.8 及以上版本
- Windows、macOS 或 Linux（均支持）

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

**Windows 用户（推荐）**：直接双击 `启动.bat`，首次使用请先双击 `首次安装.bat` 完成依赖安装。

**通用方式**：

```bash
python app.py
```

启动后浏览器会自动打开 `http://localhost:5000`。

### 3. 配置账号 Cookie

首次使用需在「设置」页面填写你的 B 站 Cookie，详见下方 [获取 Cookie](#-获取-cookie)。

### 4. 开始爬取

进入「爬取」页面，点击开始，等待爬取完成即可浏览和导出。

## 🔐 获取 Cookie

> ⚠️ Cookie 等同于你的登录凭证，请勿泄露或提交到公开仓库。

1. 打开 https://www.bilibili.com 并登录你的账号
2. 按 `F12` 打开开发者工具，切换到「网络 / Network」标签
3. 刷新页面，点击任意一个请求
4. 在「请求头 / Request Headers」中找到 `Cookie` 整行，复制其全部内容
5. 回到工具「设置」页面，粘贴 Cookie 并保存（UID 会自动从 Cookie 中提取）

> 💡 为什么不能从控制台执行 `document.cookie` 获取？因为 `SESSDATA` 是 HttpOnly Cookie，JavaScript 读不到，必须从 Network 请求头中复制完整内容。

## ⚠️ 注意事项

- 收藏夹需要设为**公开**才能爬取（爬取完成后可改回私密）
- Cookie 有时效性（通常 1~3 个月），过期后需重新获取
- 所有数据只保存在本地，不会上传到任何地方
- 爬取速度受网络和收藏夹数量影响，通常需要几分钟
- 请合理控制爬取频率，勿短时间内重复爬取，避免触发 B 站风控
